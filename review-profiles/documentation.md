# Documentation Review Profile

Use for README, docs, examples, and docstring synchronization.

## Checklist

- Public functions/classes have accurate Google-style docstrings.
- Args, Returns, Raises, and examples match actual behavior.
- README quick start and usage examples are current.
- Docs reflect changed config options, APIs, deployment steps, and workflows.
- New features or workflows have corresponding docs when user-facing.
- Links and file paths are valid.
- Examples are runnable or clearly marked as illustrative.

## Severity

- Critical: Documented behavior contradicts code, broken quick start, or dangerously stale operational docs.
- Major: Missing docs for public features, stale examples, or missing public docstrings.
- Minor: Typos, formatting, missing examples, or clarity improvements.
