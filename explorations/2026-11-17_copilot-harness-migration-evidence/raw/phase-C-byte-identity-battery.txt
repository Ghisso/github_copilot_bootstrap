Byte-identity battery, 2026-11-17: pre-phase hook scripts (git archive of 5d229e5) against the Phase C
working copy (a snapshot of shared/ taken after the last production edit).

METHOD. Every case runs once against the old tree and once against the new tree, with the same input, in
a synthetic Git repository of the same shape per tree (variants: branch main; branch dev with a big plan;
branch foo_implementation with a big plan and a small plan). Each tree's scripts are reached through a
symlink, so REPO_ROOT is the synthetic repository. The repository path is replaced by <ROOT> in the
outputs before comparing, because the two trees run in different folders. TARGET_ID is removed from the
environment, except in the sections marked [TARGET_ID exported], which export TARGET_ID=github-copilot
to a script started for another client. Harness: phase-C-battery-harness.py.txt
(python3 battery.py <old-tree> <new-tree> <report>). The final run took 5 min 57 s.

WHAT IS COMPARED. For claude-code, openai-codex, and google-antigravity: stdout bytes, stderr bytes, and
exit code must be identical. For github-copilot: exit code and stderr identical, and the new stdout must
end with the old stdout minus its first brace (so the nested object is byte-identical to the old whole
answer), with only whole top-level members `permissionDecision`, `permissionDecisionReason`, or
`additionalContext` added in front, each equal to the nested value, and no top-level `hookEventName`.
When the old code printed nothing, the new code must print nothing.

INPUTS. 84 Bash commands (dangerous git, branch creation, commits, push and pull request,
protected files, ordinary commands, a command with a tab and a newline) in three payload shapes each
(Claude Bash, Copilot toolName/toolArgs, VS Code run_in_terminal); 16 file paths in native Write, Edit,
create_file, view, read_file, grep, Copilot edit, and apply_patch shapes; the two workflow tools; 12
unreadable payloads for the fail_closed paths; Antigravity bridge payloads; context-text scripts with
closeout and commit commands; the OpenWiki guard in every mode; and the library functions called with 16
texts without a control character and 10 with control characters.
