WHEN THE OTHER THREE CLIENTS' BYTES CHANGE: only when the reason or context text holds a character from
\001 to \037 (tab, newline, carriage return, escape, and so on). Each such character becomes one space.
The output is then exactly what the old code printed for the same text with each of those characters
already replaced by a space (the `after == same as the old code ...` lines are True).
One corner: a text that ends in a newline was valid JSON before (the shell dropped the trailing newline)
and now ends in a space; see the 'ends in a newline only' block. A text with no such character gives
identical bytes (see phase-C-byte-identity-battery.txt).
